# Work in Wallet Service

**Work in Wallet Service** - это сервис дя работы с кошельками пользователей.

Он позволяет:

- Регистрировать пользователей и автоматиски создавать кошельки для них
- Получать баланс кошелька.
- Выполнять операции пополнения и возврата средств с поддержкой идеального платежа.
- Авторизавыывться и получать токен для защищенных операций.

## Запуск

- Создать файл `.env` в корневой директории проекта с параметрами как в файле `.env.example`
- Для запуска сервиса необходимо выполнить команду: `docker compose up -d`


## Документация

Документация доступна по адресу: `http://localhost:80/docs`
